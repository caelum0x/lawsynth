# Identification

LawSynth validates a declared DAG and its assumptions but does not identify an effect from a graph and an observational distribution. The library offers no back-door criterion, front-door criterion, instrumental-variable estimator, or adjustment formula evaluator.

Use identification analysis outside the current API before interpreting a simulated intervention as an empirical causal estimate. Preserve the graph, assumptions, target estimand, and analysis method alongside the model.
