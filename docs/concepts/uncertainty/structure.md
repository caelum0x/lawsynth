# Structural uncertainty

`structural_score(scores)` summarizes non-empty finite candidate scores, while `StructuralUncertainty` aggregates declared sources. Discovery returns a Pareto front so model fit and expression complexity remain visible rather than collapsing to one selected structure.

Neither function assigns posterior probabilities to equations or proves that the Pareto front exhausts plausible structures. Treat alternative candidates and scientific assumptions as part of structural uncertainty.
