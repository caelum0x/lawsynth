# Contributing

Contributions extend a real, tested behavior. Start with
[development](development.md), then choose the relevant guide: core
[architecture](architecture.md), [algorithms](algorithms.md),
[datasets](datasets.md), [operators](operators.md), [benchmarks](benchmarks.md),
or [documentation](documentation.md).

The repository rejects placeholder APIs, mock success paths, and claims based
only on file presence. A contribution for an unimplemented capability must
either implement the full boundary with verification or state the boundary
explicitly and test the rejection path.
