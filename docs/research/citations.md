# Citing LawSynth results

Treat a LawSynth result as a computational analysis. Cite the LawSynth version or source revision, input-data provenance, exact command or API configuration, model bundle checksum, and the numerical integration settings used for reported trajectories. Cite the scientific method actually used as well: for example, the selected differentiation estimator and sparse-regression procedure.

Do not cite the project as support for a causal conclusion solely because an equation was recovered from observations. State whether the claim is predictive, descriptive, mechanistic under stated assumptions, or causal under an independently justified identification argument.

Until a project release archive and DOI are established, cite a pinned source revision rather than an unversioned branch.
