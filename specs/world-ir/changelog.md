# Changelog

## 0.1.0

- Defines scalar continuous and discrete worlds, variables, parameters, and one law per state.
- Defines identifier, structural, symbol, finite-value, and optional dimensional invariants.
- Defines event crossing markers and standalone regime schedules as runtime types.
- Excludes hybrid semantics, regime-selected laws, event actions, stochasticity, delays, and provenance fields from the encoded world model.
