# Changelog

## 0.1.0

- Defines deterministic stored-ZIP archives with fixed manifest, world, and SHA-256 checksum entries.
- Defines continuous `LSW1` and discrete `LSD1` scalar World IR binary payloads.
- Defines strict archive, UTF-8, path, finite-number, expression-depth, checksum, and World IR validation.
- Provides an external HMAC-SHA-256 helper without claiming an embedded signing format or compressed ZIP support.
