# Governance

LawSynth is maintained through repository review. Maintainers steward release
decisions, security triage, architecture compatibility, and conduct matters.

Changes to public bundle formats, World IR semantics, or numerical behavior
require a written rationale, tests, and maintainer approval. Routine fixes and
documentation changes require one maintainer review; changes that affect a
normative specification or compatibility contract require two where practical.

The repository is not a foundation, company, or hosted service. Governance
documents describe the source project only and do not imply operational support
or a release schedule.
