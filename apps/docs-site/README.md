# LawSynth documentation site

This package compiles the repository's Markdown reference material into a
deterministic, accessible static site. It owns front matter, Markdown rendering,
navigation, local search, API references, examples, version catalogs,
redirects, metadata, and privacy-preserving analytics contracts.

The compiler escapes source content before introducing markup and accepts only
safe link schemes. It emits static HTML and a sitemap; deployment and CDN
configuration remain outside this package.
