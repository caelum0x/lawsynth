# Support

Use GitHub Discussions or Issues for reproducible questions about the local
Rust CLI, bundle format, or Python package. Include the command, platform,
toolchain version, and a minimal input that can be shared safely.

LawSynth currently provides no commercial support, hosted service, runtime
operations, or support-level agreement. For security reports, follow
[SECURITY.md](SECURITY.md) instead of opening a public issue.
