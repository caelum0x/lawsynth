# Maintainers

The repository owner and contributors with GitHub maintainer access administer
LawSynth. Current ownership is visible through the repository's GitHub access
controls and [CODEOWNERS](.github/CODEOWNERS).

Do not treat this document as a promise of response time, employment, or
commercial support. Report vulnerabilities through the private process in
[SECURITY.md](SECURITY.md), not by naming individuals in public issues.
